Файл index.html с последней версией сайта лежит в карточке выше, скачайте его. Дальше всё делается с ним.

1. Как редактировать самому

Откройте index.html в любом текстовом редакторе, лучше в VS Code. Проверять результат можно двойным кликом по файлу, он откроется в браузере. После каждой правки обновляйте страницу.

Заглушки: поищите по файлу (Ctrl+F) слово todo, символы [N], 20XX, you@example.com и href="#". Это все места, которые нужно заменить. У подчёркнутых полей уберите обёртку <span class="todo">…</span> и оставьте только текст.
Контакты: в блоке class="links" замените you@example.com и # на реальные ссылки, например https://t.me/ваш_ник и https://github.com/ваш_ник.
Новый проект: скопируйте целиком любой <div class="card">…</div> внутри <div class="track"> и вставьте рядом. Стрелки подхватят его сами.
Новая строка в CTF: скопируйте <div class="row">…</div>.
2. Как добавить сертификаты
Создайте рядом с index.html папку img и положите туда картинки с простыми именами латиницей без пробелов: cert1.jpg, cert2.jpg. Лучше сжать каждую до 300–500 КБ.
В index.html найдите заглушку (поищите Здесь будет картинка):
html
   <figure class="frame" style="margin:0"><div class="mono">Здесь будет картинка сертификата<br>соотношение 3:2</div></figure>

и замените её на:

html
   <figure class="frame" style="margin:0"><img src="img/cert1.jpg" alt="Сертификат: название"></figure>
В той же карточке справа замените название, год и описание.

Так для каждой карточки со своим файлом. Если сертификатов больше четырёх, скопируйте целую <article class="cert">…</article> и добавьте ещё одну строку <i class="ring"></i> рядом с остальными. Рамок должно быть столько же, сколько карточек.

Перед загрузкой закройте на сканах персональные данные: номера документов, QR-коды с личными ссылками, даты рождения.

3. Как разместить на GitHub
Зарегистрируйтесь на github.com и нажмите New repository.
Назовите репозиторий ваш_ник.github.io, и тогда сайт будет доступен по адресу https://ваш_ник.github.io. Можно назвать иначе, например portfolio, тогда адрес будет https://ваш_ник.github.io/portfolio/. Репозиторий должен быть Public.
На странице репозитория выберите Add file → Upload files, перетащите index.html и папку img и нажмите Commit changes. Файл должен называться именно index.html и лежать в корне.
Откройте Settings → Pages. В разделе Build and deployment выберите источник «Deploy from a branch», укажите ветку, например main, папку и нажмите Save. Укажите main и папку / (root).

Через 1–2 минуты вверху этой страницы появится ссылка на сайт.

То же самое через терминал:

git init
git add .
git commit -m "resume"
git branch -M main
git remote add origin https://github.com/ВАШ_НИК/ИМЯ_РЕПО.git
git push -u origin main

Обновление: загрузите файл с тем же именем заново или нажмите на карандаш у файла в GitHub и отредактируйте прямо там. Сайт обновится в течение пары минут, а в браузере нажмите Ctrl+F5.

Частые ошибки: имена картинок чувствительны к регистру (Cert1.JPG и cert1.jpg разные файлы), а пробелы и кириллица в именах файлов ломают ссылки.

Ограничения: на бесплатном тарифе Pages работает только с публичными репозиториями, а рекомендуемый размер репозитория не больше 1 ГБ. Сайт при этом будет публичным, даже если репозиторий приватный.

4. Где публиковать и куда вставлять ссылку
Хостинг: основной вариант GitHub Pages. Альтернативы с бесплатными тарифами: Cloudflare Pages, Netlify, Vercel. Свой домен вида k4d4k.dev можно подключить позже.
Куда вставить ссылку: в описание профиля GitHub (поле Website), в био Telegram, в профили CTFtime, Hack The Box и TryHackMe, в hh.ru и LinkedIn, в анкеты хакатонов и в подпись письма.
PDF-версия: кнопка «Резюме в PDF» на сайте открывает печать, там выберите «Сохранить как PDF». Её удобно прикладывать к откликам.
